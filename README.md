# 📝 To-Do List Web App

A simple and interactive **To-Do List web application** built using **HTML, CSS, and JavaScript**.

This project allows users to manage their daily tasks through a clean and easy-to-use interface.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🎨 Clean and simple user interface
- 📱 Responsive design
- ⚡ Interactive task management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
